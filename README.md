# Quick Mover

차량용 블랙박스와 GPS 로거 SD 카드를 백업 및 포맷하는데 시간도 너무 오래걸리고, 휴먼 에러 발생이 잦아 자동화하기 위해 개발된 Electron 기반 데스크톱 앱입니다.

PC에 연결된 이동식 디스크를 감지한 뒤 백업과 검증을 완료하고, 종류에 맞게 포맷합니다. 데이터 안전을 위해 장치 식별 정보와 백업 결과를 확인하지 못하면 포맷하지 않습니다.

## 주요 기능

- 이동식 SD 카드 자동 감지
- 파일 시스템 기반 카드 종류 추천
  - FAT32 → GPS 로거
  - exFAT → 블랙박스
  - 시간대 기본값은 단일
- SD 카드별 메모 설정
- SD 카드별 백업 경로 설정
- 파일만/주간/야간 선택 옵션 제공
- 백업 경로 즐겨찾기 추가/선택/삭제 제공
- 날짜 폴더 생성 여부를 SD 카드별 제공
- 단일 파일, 폴더, 다중 파일 선택 백업
- 선택 백업 전 미선택 데이터 삭제 확인
- 파일명 충돌 시 `_1, _2` 순서로 자동 변경
- 파일 수, 크기 비교 또는 SHA-256 전체 검증
- 백업 완료 후 결과와 오류 상태 표시

## 백업 경로 구조

백업 폴더 생성 옵션과 시간대에 따라 다음과 같이 저장됩니다.

```text
단일 + 폴더 생성    <백업 경로>/yyyy-mm-dd/파일
주간 + 폴더 생성    <백업 경로>/yyyy-mm-dd/1/파일
야간 + 폴더 생성    <백업 경로>/yyyy-mm-dd/2/파일

단일 + 폴더 미생성  <백업 경로>/파일
주간 + 폴더 미생성  <백업 경로>/1/파일
야간 + 폴더 미생성  <백업 경로>/2/파일
```

같은 목적지에 같은 파일명이 있으면 원본 파일을 덮어쓰지 않고 이름에 숫자 접미사를 붙입니다.

## 포맷 규격

| 종류 | 볼륨 유형 | 할당 단위 |
| --- | --- | --- |
| 블랙박스 | exFAT | 128 KB (`131072` bytes) |
| GPS 로거 | FAT32 | Windows 기본값 |

포맷 직전 현재 장치를 다시 조회하고, 선택한 장치와 물리 디스크 식별자가 다르면 작업을 중단합니다. 시스템, 부팅, 고정 디스크 또는 백업 대상과 같은 드라이브는 포맷할 수 없습니다.

## 프로젝트 구조

```text
src/
  main/
    ipc/
    platform/windows/
    services/
  preload/
  renderer/
  shared/

  e2e/

```

Renderer는 UI와 IPC 호출만 담당하며, 파일 시스템, 드라이브 조회/백업/포맷은 Electron Main 프로세스의 서비스 계층에서 처리합니다.

## 개발 환경

Node.js 22 이상과 pnpm 10 이상이 필요합니다.

```bash
pnpm install
pnpm dev
```

## 검증 및 빌드

```bash
# TypeScript 검사
pnpm typecheck

# ESLint
pnpm lint

# Production 빌드
pnpm build

# Windows 설치 프로그램
pnpm package:win

# 설치 없이 Windows 패키지 생성

```

Playwright 테스트는 실제 디스크를 포맷하지 않으며, OS 및 디스크 기능은 mock 플랫폼을 사용합니다.

```bash
pnpm test:e2e
```

## 설정 저장

Electron의 `userData` 경로에 `settings.json`으로 저장됩니다. 저장되는 주요 항목은 다음과 같습니다.

- 백업 경로 즐겨찾기 목록
- 검증 방식
- 물리 디스크 식별자별 백업 경로
- 물리 디스크 식별자별 날짜 폴더 생성 여부

드라이브 문자는 고정된 장치 식별자로 저장하지 않습니다.

## 안전 원칙

1. 백업과 백업 검증이 성공하기 전에는 포맷하지 않습니다.
2. 포맷 직전에 장치 식별자를 다시 검증합니다.
3. 장치 제거, 식별자 변경, 검증 실패가 발생하면 실패 상태로 중단합니다.
4. 원본 파일은 복사 중 수정하거나 삭제하지 않습니다.
5. 실제 디스크를 대상으로 하는 포맷 명령은 자동화 테스트에서 실행하지 않습니다.

잘못된 장치로 판단될 가능성이 있으면 작업하지 않고 오류를 반환합니다.
